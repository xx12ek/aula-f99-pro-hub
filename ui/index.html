为什么方向能分开：键盘固件已经把「顺时针 / 逆时针 / 按下」翻译成三个不同的系统按键（音量+ / 音量− / 静音）， 软件在半路把它们接过来，就能各干各的。

提示条从哪来：绑成「系统默认（音量 / 静音）」时会放行真实按键，由 Windows 自己画那条原生条 —— 实测这是唯一能出系统原生条的办法（程序直接改音量 / 改屏幕亮度，系统一律不弹条）。 绑成别的动作时按键被截下来，改由本软件画一条按系统原生条逐像素复刻的提示条（170×45 圆角矩形、跟随系统强调色）。

想要屏幕亮度也出系统原生条？旋钮这边的「屏幕亮度 +/−」是软件直接改亮度，系统不会弹条。 要原生条只有一条路：去改键页把某个物理键绑成多媒体 → 亮度+ / 亮度−， 由键盘固件自己把亮度键发给 Windows（已实测可写、可还原），按那个键就会看到系统自己的亮度条。

当前功能：—
这个功能不在实测验证过的 7 种里。键盘会把记录存下来，但转动旋钮时到底报不报得出来没有把握 —— 试完不行就点「恢复出厂」。

上面那条 #108 记录决定「旋钮整体往电脑报什么」，和普通键同级，能随便改； 三个方向的细分动作则在「转动方向分开绑」里配。 「长按 2 秒切办公 / 游戏模式」是固件内部行为，这两处都改不掉它。
