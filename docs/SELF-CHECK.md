## 这些项各自意味着什么

| 检查项 | 说明 |
|---|---|
| 身份/型号 | 发 `0x82` 参数 1，返回 `03 00 00 00 01 58`（`0x58` = F99 Pro） |
| 矩阵读取 | 512 字节 = 128 键 × 4 字节，4 层都能读 |
| 改键解码层数 | 默认 / FN1 / FN2 / Tap |
| 键位表 | `core/keymap.json`，99 个有几何坐标的键 |
| 灯效种类 | 19 种硬件灯效 + 「关闭」 |
| 逐键颜色读取 | 126 个灯位 |
| 宏库读取 | 10240 字节 |
| 灯效切换 / 背光 / 速度 / 休眠 | **写→读回→还原**，三次都比对过 |
| 配置页回写 | 整页 128 字节写回后逐字节比对 |
| 系统音量 / 静音 | WASAPI 通道（不是失效的 `waveOutSetVolume`） |
| 屏幕亮度 | WMI（笔记本内屏） |
| OSD 尺寸 | 与 Windows 原生条逐像素对齐后的结果（170×45 逻辑像素） |
| OSD 强调色 | 从注册表 `Accent\StartColorMenu` 读（AABBGGRR 字节序） |
| 旋钮动作表 | 15 种可绑定动作 |
| 原生放行表 | 绑成「系统默认」时这三个键放行给 Windows，弹原生音量条 |

## 2.4G 下的差异

无线连接时以下项会自动跳过（协议层不支持写）：

- 配置页回写 → 保留（`0x04` 无线可用）
- 宏库读取 → 跳过（无线通道没有这个命令）
- 逐键颜色**写**入 → 跳过（只能读）

其余全部通过。实测数据见 `docs/PROTOCOL.md` 第 3 节。
